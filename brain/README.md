# Brain

The source for what's true about the business. Every agent reads from here. Prices and offers will show up in pages, ads and emails, so each one is copied from here and checked against here, never retyped from memory. When a copy and these files disagree, these files win.

Only the owner, or the chief of staff on the owner's word, edits these files. When something changes, edit it here and add a line to memory/DECISIONS.md saying what changed.

- business.md: what you sell, to whom, what makes it different
- voice.md: how you sound, words you use and never use
- offers.md: every offer and price. The source every other price is checked against.
- clients.md: who your customers are, and any you're working with now
- sops/: processes, written by ops-sop-writer
