# Memory

What happened, as opposed to what's true (that's brain/). Append only. Never edit or delete a line. A changed fact gets a new line that says what it replaces.

- DECISIONS.md: decisions and outcomes. Before anything that spends, sends, deploys or deletes, log the decision and what you expect. Log the outcome when it shows up, even if the guess was wrong.
- FACTS.md: facts learned along the way that agents should know next time.
- IDEAS.md: new ideas parked so they don't hijack the week. Only the owner promotes one.

When agents work from more than one surface (phone, claude.ai, another model), move this folder into an MCP memory server so they all share it.
