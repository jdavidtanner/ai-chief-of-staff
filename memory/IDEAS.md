# Ideas

A new idea is not a new priority. Park it here. Before the owner promotes one, answer:

1. Does it move this quarter's one outcome (brain/business.md)?
2. What would it replace this week?
3. What's the smallest test that would prove it?
4. What does it cost in hours and dollars?
5. Would it still look good in two weeks?

Format: date | idea | source | answers | status (parked, promoted, dropped)
